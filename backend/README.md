# Mithu Homemade Cakes - Backend

This backend directory is intentionally empty for the current version. 

As per the project requirements, the current ordering system operates entirely through **WhatsApp**. There is no database, no authentication, and no payment gateway required at this stage.

## Future Expansion
This directory is reserved for future scalability. When the business requires a full order management system, database, and admin panel, the backend API should be implemented here (e.g., using Node.js/Express, Python/Django, etc.).
